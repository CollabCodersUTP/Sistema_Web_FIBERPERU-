# 📐 Diagramas del Proyecto - FIBERPERU E.I.R.L.

En este directorio se almacenan los diagramas de arquitectura y modelado de procesos:

1. **BPMN (Bizagi / Draw.io):** Proceso AS-IS y TO-BE de atención e instalación de dispositivos de red.
2. **Modelo Entidad-Relación (DER):** Diagrama de base de datos relacional para PostgreSQL.
3. **Diagramas UML:** Diagramas de Casos de Uso, Secuencia y Clases.
4. **Arquitectura Cloud:** Diagrama de despliegue en Microsoft Azure.
