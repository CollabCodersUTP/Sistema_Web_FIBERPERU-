# 📄 Documentación del Proyecto - FIBERPERU E.I.R.L.

Este directorio contiene la documentación formal del proyecto académico UTP ("Sistema web para la gestión y seguimiento de la instalación de dispositivos de red en FIBERPERU E.I.R.L."):

1. **[Especificación de Requerimientos y Product Backlog](./ESPECIFICACION_REQUERIMIENTOS_Y_BACKLOG.md):** Documento formal con los 23 Requerimientos Funcionales, 14 Requerimientos No Funcionales, 16 Reglas de Negocio, 12 Restricciones del Sistema y Product Backlog (PB-01 a PB-14).
2. **Project Charter & Acta de Constitución:** Objetivos, cronograma de 18 semanas (Gantt) y roles del equipo de desarrollo.
3. **Manuales de Usuario y Técnico:** Guías de instalación del backend Spring Boot, frontend Next.js, base de datos PostgreSQL y despliegue en Microsoft Azure.
